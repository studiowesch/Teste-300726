# Foco & Design

Um timer Pomodoro de página única que ensina uma curiosidade sobre design de móveis a cada pausa.

## Como usar

Abra o arquivo [`index.html`](./index.html) diretamente no navegador — não há dependências nem processo de build.

## Funcionalidades

- Timer Pomodoro com duração de foco e pausa configuráveis
- Uma curiosidade de design de móveis exibida a cada pausa
- Lista de tarefas da sessão
- Alternância de tema claro/escuro
- Tudo roda no navegador; nenhum dado é enviado para fora
